# 同人誌管理ツール

個人用の同人誌管理 & イベント購入リストPWA。データはブラウザ内（IndexedDB）にのみ保存されます。

## 機能

- 📚 **同人誌管理**：書名・サークル・作家・金額・購入日・場所・備考＋カスタムフィールド
- 🎪 **イベント管理**：複数イベント、フロアマップ画像にグリッド自動配置
- 🎨 **5色のスペースステータス**：最優先(🔴) / 欲しい(🟡) / 特別(🔵) / 購入済(🟢) / 購入しない(✕)
- ⚡ **ワンクリック購入確定**：大きな「はい」ボタン、同人誌管理に自動登録
- 📧 **Gmail連携**：BOOTH / とらのあな / メロンブックス の購入メールを自動取込
- 💾 **バックアップ**：JSONで書き出し・読み込み
- 📱 **PWA対応**：iPhone・Windowsのホーム画面に追加可能

## セットアップ（初回のみ）

### ステップ1：GitHub Pages で公開する

1. [GitHub](https://github.com/) でアカウント作成（済なら省略）
2. 新しいリポジトリを作成（例：`doujin-manager`）→ Public でOK（データは入りません）
3. このフォルダの中身をすべてアップロード
4. リポジトリの **Settings → Pages** → Source を `main` ブランチ、フォルダは `/ (root)` にして Save
5. 数分待つと `https://<あなたのID>.github.io/doujin-manager/` で公開される

### ステップ2：iPhone / Windows でアプリとして使う

- **iPhone**：Chrome で上のURLを開く → 共有ボタン → 「ホーム画面に追加」
- **Windows**：Chrome で URL を開く → アドレスバー右の「インストール」アイコン

### ステップ3：Gmail連携（任意）

購入メールからの自動取込を使う場合のみ必要です。

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセス
2. プロジェクトを作成（例：`doujin-manager`）
3. **APIとサービス → ライブラリ** で「Gmail API」を有効化
4. **OAuth同意画面**：外部、アプリ名入力、スコープに `gmail.readonly` を追加、**テストユーザー**に自分のGmailを追加
5. **認証情報 → 認証情報を作成 → OAuthクライアントID**：
   - アプリの種類：**ウェブアプリケーション**
   - 承認済みのJavaScript生成元：`https://<あなたのID>.github.io`
6. 作成後の **クライアントID** をコピー
7. アプリ内 **設定 → Gmail連携** にクライアントID を貼り付けて保存
8. 「Googleでログイン」

> 🔒 **セキュリティ**：`gmail.readonly` なので読み取り専用。メール内容はブラウザ内でのみ処理され、外部に送信されません。

## 使い方

### 📚 同人誌管理

- 右上「＋追加」で手入力
- 「Gmail取込」でメールから自動候補を表示、チェックして登録

### 🎪 イベント管理

1. イベント追加（名前・日付・会場・フロアマップ画像）
2. イベント詳細画面でグリッドが自動配置される
3. **グリッド設定**ボタンで行×列・位置・セルサイズを微調整
4. 各スペースボタンをタップしてサークル情報と欲しい度を登録

### 🎛 3つのモード

| モード | タップ時の動作 |
|---|---|
| **チェック** | 最優先/欲しい/特別のスペース → 購入確認ダイアログ → 購入済＋本棚に自動登録 |
| **情報** | そのスペースの登録情報を表示 |
| **編集** | スペース情報を編集 |

### 🎨 カスタムフィールド

**設定 → カスタムフィールド** で「要注意」など独自の項目と選択肢を設定できます。同人誌管理・スペースの両方で使えます。
